# dsh-memory-ACC

给 DeepSeek Harness 的第二个记忆引擎。与 `dsh-memory`（标准版）**二选一**，不叠加。

一句话区别：**标准版记结论，ACC 记一个人。**

---

## 它想解决的事

**它每次都不记得我。**
开一个新会话，它重新认识你一遍。你记得它，它不记得你——这关系是单向的。

**上次那个结论呢？**
你明明记得聊过，但翻不回去。上下文一清，那段就像没发生过。

**我给它看的图，它还说没有。**
它确实没有。只留了一个编号。

**它记得的是结论，不是我们。**
三个月后你看到的是"用户偏好简洁回复"，而不是那晚你们怎么一句一句把一件事聊明白的。

**我不想再配一把 key。**
harness 已经登录好了，凭什么记忆还要自带钥匙。

**万一被改过呢？**
没有版本、没有只读、没有备份。记忆被悄悄改掉，你发现不了。

---

## 相对标准版，多了什么

|  | 标准版 | **ACC** |
|---|---|---|
| 记什么 | 每轮萃取成一两条结论 | 完整对话原文，一字不截 |
| 怎么给模型看 | 结论直接进上下文 | 先描摹成印象再注入，原文留库 |
| 记得谁 | 一个抽象"用户" | 分开记「你」和「我」 |
| 图片 | 只留 attachment id | 留"这张图讲了什么" |
| 模型接入 | 需要 key 或借用登录态 | **默认借用，零配置** |
| 长期留存 | 删了就没有 | **金字塔，写入即只读** |

### 逐条对应

**"它不记得我"** → 八面档案每轮注入最近几条。新工作区一开口就知道你是谁、怎么说话。

**"上次那个结论"** → `acc_search` 只要求你记得几个词，不要求原话。

**"我给的图它说没有"** → 图由模型自己描述，存文字不存像素。原图没了，至少还剩"这张图是什么"。

**"记得的是结论不是我们"** → 归档不截断、不萃取。压缩只发生在注入层。

**"不想再配 key"** → 默认用 harness 登录态。想指定别的模型，也留了口子。

**"万一被改过"** → 备份写入即 444 只读，程序永不重写；年度层永久保留。

## 六个部件

**完整对话归档**
每轮之后从会话日志自动提取，不靠模型汇报。原文完整保留。

**性格八面**
从对话里描摹两个对象——**你**和**我**。都是主观印象，但每条有明确归属，不会互相冒充。

```
性格 · 口吻 · 好感 · 习惯 · 喜欢的物品 · 习惯的作风 · 风格 · 能力
```

**二级记忆**
该活过这个会话的结论。上限 80 条，最新优先，每轮注入最近 6 条。

**恍惚**
有些事不用被问，会自己浮上来。

二级记忆里另存两类：**每日有意思的事**、**每日尴尬的事**。整理曲线按**被调用权重**排序（用进废退），不看新旧。

检索时有 **3%** 概率浮现一条权重最高的事件，措辞是"忽然想起"，并标注"和现在未必有关"。

**每 24 小时最多 2 次。** 它不是彩蛋，是稀缺性——多了就是噪声。

**备份金字塔**
日 → 周 → 月 → 年，逐级归并，归并后删下级冗余。

写完之后只有两种结局：**删除，或永久只读**。没有"改一下"这种中间态。删掉的进 `trash/`，留 7 天。

**常驻聊天**
一条独立工作区里的固定会话，从侧边栏绿点条目进入。**设定完成后就是绿点「已启用」，不会多出一条。**

输入框左边另有胶囊：绿「记忆」/ 蓝「ACC」/ 灰「关闭」。

---

## 边界

**不改发给模型的请求。**
请求是会话日志的纯函数，插件只能读不能改。所以"只保留最近 N 轮"ACC 做不到，靠 harness 自己的压缩。

**不隐藏宿主 UI。**
工作区里的「＋新会话」按钮去不掉，那是宿主渲染的。

**不是第二个 agent。**
它是记忆。

## 安装

拷进 profile 的 `node_modules/dsh-memory-acc`，在 `cordis.patch.yml` 加一行（**这个文件必须是顶层数组**）：

```yaml
- insert:
    - id: memory-acc
      name: dsh-memory-acc
```

重启 harness。

### 与标准版共存

两个都装不会打架：ACC 会自动让位——工具停用、上下文不注入，只保留设置页和状态接口。

选「改用 ACC」会写 patch 禁用标准版；选「保留标准版」则停用 ACC 自己。选完不再打扰，设置页里有「重新检测冲突」。

## 配置

全部在 **设置 → 记忆 · ACC**：

| 区块 | 内容 |
|---|---|
| 引擎 | 装了哪些引擎，冲突时红字提示 |
| 常驻聊天 | 选目录 → 自动建工作区 + 会话 |
| 存储 | 归档位置 / 备份位置 / 加密开关 / 备份目录 |
| 记忆模型 | 默认借用 harness，也可手填覆盖 |
| 档案 | 你/我 各八面条数、二级记忆、恍惚条数 |

---

## 四条设计取舍

**印象不是档案**
注入的是"你说话很简短"，不是完整原文。原文在归档里，需要时检索。

**存储不截断**
tool 输出、assistant 文本都完整保留。压缩在注入层，不在存储层。

**备份不可变**
一个能被改写的备份不能算证据。

**图片只留描述**
不复制二进制。由正在看图的模型写出描述——它看得到，记忆库看不到。
